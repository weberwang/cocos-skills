# Worktree 工作区隔离

Worktree 不是默认能力。只有人工明确要求且确有多个并发写入者时，才用它隔离文件修改和 Git 状态；它不作为质量门、角色交接、阶段交付物或自动收敛机制。

- 已明确授权：每个并发写入者使用独立 worktree 和分支，并明确文件或模块归属；不得让两个写入者修改同一文件。
- 未明确授权或无需隔离：直接使用当前工作区，并通过独占文件归属或串行写入避免冲突。单个写入者、顺序任务和只读任务始终使用当前工作区。

任务完成后在对应 worktree 运行必要检查，并按普通 Git 流程提交和集成。删除 worktree 或分支前重新确认工作目录干净、提交已保留且目标明确；不自动合并、清理或强制删除。
