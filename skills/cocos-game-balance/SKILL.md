# Cocos Creator 3.x 数值设计

## 全局控制接入

控制面边界：可提议、可审查、可在当前用户任务的 Work Item 范围内修改，且必须回到 `$cocos-game-workflow-control` 审计和状态迁移；仅涉及外部写入、付费、真机、破坏性或外部删除、发布副作用的 A4-A6 操作请求批准。

本领域可提议、审查，并在当前用户任务、Implementation Package、A 等级与路径范围内修改；变更结果必须回到 [`cocos-game-workflow-control`](../cocos-game-workflow-control/SKILL.md) 审计和状态迁移，仅涉及外部写入、付费、真机、破坏性或外部删除、发布副作用的 A4-A6 操作请求批准。

将体验目标转为可解释、可调整、可验证的模型，不以未记录的主观调参替代证据。

汁水感调整涉及顿帧、硬直、实际击退、吸附或输入容错等规则参数时，按[玩法与表现边界](../cocos-game-juice/references/design-guide.md#设计原则与玩法边界)与玩法共同确定影响和验证；纯粒子、声音或视觉偏移不因此进入数值修改范围。

读取全局 Work Item、项目配置、GDD、当前玩法实现和数值模型。按 F0 范围与流程、F1 规格一致性、F2 数值质量、F3 模拟/实测/回归证据和 F4 集成/发布决策推进。

1. 定义玩家节奏、成功率、资源来源与消耗、失败成本和保底机制。
2. 在 balance.md 记录参数、单位、默认值、来源、影响、公式和验证方式；运行时集中读取配置。
3. 为高风险曲线保留可复现计算与试玩记录；涉及合规或商业能力时同步发布合规角色。
4. 标准、发布通道向总控提交一条模型版本、关键证据或阻断项，由总控更新控制面；快速通道仅在产生未决决策或阻断项时提交。

交给玩法的是参数表、边界行为和验收样例；交给测试的是关键场景与预期结果。
