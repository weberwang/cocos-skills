# 模型交接

本清单为 3D 建模与任何下游贴图、绑定、动画、玩法接入或 QA 工序提供自包含接口；不要求这些生产技能位于同一仓库，也不由建模技能包办。交接记录属于现有 Work Item 和证据，不创建新状态或确认阶段。

## 建模交付

| 交接项 | 建模方提供 | 下游读取与限制 |
| --- | --- | --- |
| 身份与文件 | 资源 ID、当前模型候选/版本、版本化 `.blend`、运行时导出文件、实际路径、对象/Collection 和许可记录 | 按实际路径绑定源、对象与运行时资源；不得依据“最新版”或文件名猜测身份 |
| 最终网格 | 运行时网格、变换/Pivot/坐标约定、拆件边界、修改器和三角化策略、硬边、法线/切线策略 | 以同一导出网格作为下游基准；涉及几何或法线的变更需回到建模责任人处理 |
| UV 与纹理集 | 实际 UV 通道名/用途、岛与接缝位置报告、允许重叠区域、密度/Padding 目标、材质槽到纹理集映射 | 只读检查越界、拉伸、重叠和密度；镜像、UDIM 或重叠 UV 明确真实可用方案，不暗中重排或重展 |
| 材质槽与 LOD | 材质槽名称/顺序/面分配、每级 LOD 的网格与 UV/图集共用策略、碰撞代理身份 | 向既有槽位绑定材质；未获范围变更不得增删重排槽位、改面分配或将碰撞代理纳入外观烘焙 |
| 烘焙输入（按需） | 匹配高低模及对象命名、Cage 网格与使用规则、投射射线/隔离分组建议、法线/切线与三角化约定 | 由下游烘焙者读取并实施；输入不合格退回建模，不能修改已交付 Cage 或暗改低模补救 |
| 角色拓扑（按需） | 关节环线、变形区拓扑、BlendShape 目标几何、顶点顺序限制和静态模型版本 | 绑定/动画生产者据此创建骨架、权重及动作；贴图等下游保持网格与变形数据只读。本技能不实现骨架、蒙皮或动作 |
| 外观与预算 | 视觉基线、目标机位/距离、表面分区、必须建模与可由贴图表达的细节、面数/纹理/内存预算、已知问题和许可 | 识别视觉与性能约束冲突，并在当前工作项范围内回报或退修 |

高模、Cage、额外 UV、LOD、碰撞和角色拓扑等不适用时写明原因，不虚构工件。仍为 blockout、缺少关键 UV/槽位信息、源与实际导出不一致，或存在未解决的法线/拓扑问题时，受影响下游操作保持 `BLOCKED`。

## 变更和局部复验

原始来源只读，修改写入版本化派生文件。建模方拥有几何、UV、法线、槽位结构、LOD、碰撞代理和静态模型导出；下游不得将派生网格覆盖回正式运行时模型。同一个 `.blend`、资源 ID、Creator 项目和导出目录保持单写者，Creator 编辑器写入按[协议](../../cocos-game-workflow-control/references/cocos-mcp-protocol.md)串行。

| 实际变化 | 至少复验的依赖 |
| --- | --- |
| 几何、三角化、法线/切线、高模或 Cage 变化 | 受影响法线/AO 等烘焙输入、相关材质/贴图、导出回读和 Creator 网格导入 |
| UV、纹理集、槽位/面分配或 LOD 用图策略变化 | 受影响烘焙/绘制/打包、材质绑定、LOD Renderer 与正式场景使用 |
| 仅 Collider 变化 | 对应碰撞形状、物理交互及玩法空间 |
| 仅命名、路径、导入身份或 UUID 变化 | 真实资源查询、引用读回和使用该资源的 Prefab/Scene |

复验范围按实际依赖决定，不因小改动重跑无关工序。问题交回时提供资源 ID、源版本和路径、对象/UV/槽位/LOD 定位、预期与实况、受影响消费者及建议修复；在当前 Work Item 内处理并记录验证结果。
