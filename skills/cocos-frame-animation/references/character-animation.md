# 角色帧动画

本参考用于通过身体动作表达意图、移动、受力或姿态变化的角色与生物动画。完整时间轴、单元边界和播放设置遵循[完整动作与时间轴](action-timing.md)；本文件聚焦身体表演、玩法约束和人工验收。

## 行为类别与边界

角色行为可以是循环运动（如呼吸、行走或奔跑）、主动行为（如转身、使用物件或攻击）、被动反应（如受推、失衡或倒地），也可以是连续组合。类别用于选择表现重点，不决定行为单元、视频批次或运行时 key 的数量；循环、单次、组合播放和终态保持是独立播放设置。设计首先追求有吸引力、能体现角色个性的完整表演；动作重量感、夸张幅度、停顿和跟随关系按任务体验目标、角色设定与项目基线推导，不预设统一的保守程度或炫技风格。

同一完整角色行为共享覆盖整组的时间轴和预览，默认整体制作。对已定义的完整连击，即使运行时由多个既有输入门逐段推进，也在整组时间轴上标出各段事件和允许的输入衔接，不因拳数拆成独立生成任务。确需分段生产时，按[完整动作与时间轴](action-timing.md)中的分段规则处理；生产分段与运行时动画 key 分别按各自已有合同确定，本分类不固定生成任务、视频或 key 数量。

整组预览用于审阅完整行为，不表示一次输入会自动播放全部段。玩家只输入当前段时，后续推进必须满足已有输入门和状态条件；条件未满足时，不能借预览暗示自动继续。若玩法合同已定义自动或手动推进，按既有机制表现，不改变输入方式及推进、取消或受击打断权限。

战斗动画以当前玩法合同为边界：沿用已经定义的触发、输入机制、事件时刻、推进、取消、受击打断和其他权限。不得靠增加视觉出手来增加攻击次数、制造自动连击或暗示额外伤害。需求未说明某项行为是否可取消、会否被打断或事件何时生效时，记录为待澄清，不代替玩法作决定。

角色素材是否包含特效、声音或镜头反馈，只按当前素材合同决定。角色身体动作的存在不表示这些反馈必须烘入角色帧；若由单独资源承担，则按对应合同保持独立。

## 设计依据与交付内容

角色动画设计师把角色身份、动作意图和身体运动转化为有感染力、可读且符合玩法边界的表演。任务分工遵循[动画导演／动作指导职责](animation-direction.md)：简单任务由该设计师兼任导演，需独立统筹的复杂表演或紧密跨类型协作由导演提出构思；仅类型并列或合批不自动增加岗位。设计依据包括：任务体验目标和观看情境；已定义的角色性格/气质、行为目的和情绪读感；既有玩法事件、状态条件、输入门、分支及打断/取消权限；真实角色素材、已批准造型参考、视角和项目动画基线。运动判断结合角色体型、支撑与重心、肢体发力链、惯性以及持有物关系。性格读感或艺术动作未细化时，提出并记录服务于观看体验的设计假设形成方案；仅当决定性玩法事实或行为权限无法从现有材料推导时标待澄清，不自行扩大玩法权限。

交付到当前 Work Item 设计工件：

- 明确希望观众获得的感受、角色表演亮点和最值得观看的动作变化；说明关键阶段如何建立期待、形成变化并完成收势或留下记忆点。
- 按任务选择关键姿态、身体朝向与空间轨迹，说明转身、侧身、旋身、翻腾、透视缩短、夸张形变、遮挡和节奏反差等手段是否有助于表演；这些是可选设计手段，不是每个动作的必做清单。记录各阶段如何衔接、重心和根运动如何变化、角色自身左右肢体与装备身份如何连续；每个玩法事件对应可观察的姿态或动作时点。
- 说明前置/后续动作的入姿、出姿和既有切换条件；记录循环进入/退出或单次终态去向，以及图片/视频制作所需的动作与身份约束。
- 记录动作幅度、节奏、姿态与比例变化、细节取舍分别依据的表演目标、角色设定、真实素材或显示情境；时长、帧数、角度、位移和尺寸等参数按本任务推导并说明理由，沿用现有播放和玩法合同。

## 衔接与循环设计

每个角色动作在制作首尾或选择视频有效区间前，明确是否循环，以及从何种动作/状态进入、结束后接何种动作/状态。依据当前任务与已有玩法合同判断，不因“待机”“攻击”等名称自动决定，也不把“连续组合”视为循环。相关参数记录在[共用时间轴的设计工件](action-timing.md#游戏时间先于来源)，不新增运行时状态机或合同字段。

- **设计动作间的交接。** 记录前置动作的出姿、当前动作的入姿/出姿、后续动作的入姿及允许切换时点；核对语义根、朝向、重心、承重脚、肢体/武器轨迹和运动速度的承接。必要过渡纳入已定义的动作时序，不强制所有动作使用同一站姿或增加独立动画 key。只有阶段内部连续，不足以证明动作间衔接成立。
- **单次动作设计去向。** 明确收势后返回哪个动作、进入哪个终态或保持到什么条件；尾帧按该去向设计，不要求与首帧相同，也不自动重播。已有合同允许取消或受击打断时，检查允许切换点到目标动作的衔接；不能为播放完整收势而自行延迟输入响应或取消权限。
- **循环动作设计闭合与退出。** 除周期内部运动外，检查末段到下一周期首段的姿态、方向、速度、重心与承重相位；首尾相似不能代替跨周期连续。分别记录进入循环的过渡，以及按现有合同即时退出、在指定相位退出或完成周期后退出的条件。进入、持续循环与退出需要分别审阅，不能只把一段动画重复播放。
- **连续组合设计阶段连接与分支。** 后段准备承接前段随动和重心，不在每段之间无故回到初态。整组末尾的去向与每个既有输入门未满足时的去向分别记录；不会因为内部有衔接而自动追加后段。未定义的目标状态、切换权限或循环退出条件标为待确定，不由美术补设玩法。

交接姿态在时间轴设计中说明行为、承重和时序关系，实际姿态与视觉连续性用真实美术素材人工检查，设计图表不提供占位造型约束。

## 制作与优化判断

- **先塑造值得观看的表演。** 根据体验目标安排动作亮点、身体朝向变化、空间轨迹与节奏反差。侧身、旋身、翻腾、透视缩短、遮挡和夸张形变可用于建立期待、释放动作或突出角色个性；按任务需要选择，不为炫技而强加。关键姿态和轮廓应帮助观众读懂表演，不要求各帧维持相同视角、轮廓或可见比例。
- **让重心和支撑服务于动作。** 行走、起跳、落地、推拉和失衡等动作需让承重关系与重心变化可理解；扎根脚在计划支撑阶段应有合理接触，腾空时应看出离地与落地。根运动、轨迹和锚点依据整段表演设计，允许随跨步、腾空、翻转或大幅位移变化；检查是否为有意运动，不能把所有根位移都判成漂移。
- **区分设计好的姿态变化与身份漂移。** 依据真实角色素材和造型设定检查角色身份、装备、解剖关系及运动连续性。转向、透视缩短、压缩拉伸和遮挡可使头身比例、肢段可见长度及轮廓发生合理变化；重点判断这些变化是否有动作原因且前后连贯，不要求每帧保持相同可见比例或正面形态。未设计的整体缩放、换装或无因跳变才作为问题处理。
- **保持角色自身肢体与装备身份连续。** 在设计工件与提示词中明确角色自身的左右肢体、持物手及装备身份，沿运动链检查衔接。角色转身会让肢体在画面中的左右位置、近远关系和遮挡顺序自然交换，这不等同于换手或身份错误。未规划的真实换手、装备替换或肢体身份跳变才需修正；确需交接时安排清楚的姿态和轨迹。
- **让发力与惯性有因果。** 主动动作可按项目风格包含预备、发力、随动和恢复，但不要求固定的蓄力或停顿。判断躯干、肩髋、手臂、腿部和道具的先后关系是否支持动作方向；反向、急停或撞击后的延迟应符合角色质量与视觉基线。被动反应要看出受力来源与身体跟随，不能把反应画成主动攻击。
- **用速度变化与夸张建立表演层次。** 按任务推导加速、减速、停顿、反向、跟随与形变，让观众感受到动作重点；不限制动作必须小幅或持续朝向镜头。夸张程度服务于角色个性和观看效果，验收身份与运动因果是否仍清楚，并遵守实际显示边界。
- **用衔接表达连续性。** 转向、跨步、连续攻击、受击到倒地等阶段，检查重心、朝向和四肢轨迹能否连起来。复合行为中应沿用已有的玩法事件时序，不在视觉上添加额外出手或把同一事件表现成多次生效。
- **循环检查承重跨周期。** 对步行、奔跑等循环，逐周期确认承重交替、接触和腾空符合所设计的步态，循环接缝动作连续；角色按设计移动时根轨迹可以推进，不要求原地固定。呼吸等小循环也要检查首尾幅度或速度是否无意跳变。

优化选择、关键姿态与玩法事件的依据保存在当前 Work Item 设计工件中；本参考不扩展运行时合同或 accepted schema。

## 人工验收重点

1. **先完整观看表演：** 连续播放整段动作，判断是否吸引人、是否体现角色性格、动作亮点是否清楚、节奏是否有变化且结尾是否有记忆点；先确认预期的转身、空间轨迹、透视、遮挡或夸张是否服务表演，再进入逐帧检查。
2. **动作意图、身份与运动连续性：** 起始、动作极值、事件帧、恢复或终态是否传达预期意图；角色造型特征、装备和角色自身左右肢体身份是否连贯。正侧背转向、画面左右交换、合理透视缩短、遮挡和形变不作为缺陷；检查无因跳变、身份错乱和无法解释的运动断裂。
3. **支撑、根运动与发力：** 脚掌接触、腾空和重心变化是否符合当前表演，根轨迹是否与计划移动相符；身体各部分的动作次序是否说明力量方向，停顿、反向和随动是否具有动作目的。只把未设计的滑动或漂移作为问题。
4. **事件和权限：** 依照已有玩法时间轴核对动作事件，不把视觉出手数当作命中数；确认没有添入未经定义的自动衔接、推进、取消或受击打断表现。时序或权限未定义时保留问题，不以美术验收替代玩法确认。
5. **完整播放边界与动作间衔接：** 按允许路径检查“前置动作→当前动作→后续动作”的入姿、出姿、重心和速度承接；循环分别检查进入、多周期承重/接缝及退出，单次检查收势、终态和后续接入，连续组合检查整组及既有分支。缺少相邻真实素材时保留未验证项，不以单帧、孤立片段或内部设计记录替代正式衔接验收。

图片路线的逐张制作与人工放行遵循[一致性及衔接门](image-inbetween.md#关键帧的一致性与衔接门)。每张既检查真实比例、支撑与持物手，也检查是否完成当前阶段的发力方向和轨迹；不能以“更接近待机”代替正确准备、事件或恢复姿态。视频路线保留连续运动来源，局部修帧仍检查相邻真实帧，不能因文件结构通过而省略上述人工判断。

## 分类边界

身体的姿势与位移属于角色动画；独立爆闪、烟雾、光环等按[特效帧动画](effect-animation.md)判断；普通物件或机关按[物件、环境与机械动画](object-animation.md)判断。战斗特效、音效和镜头抖动是否随角色资源制作，始终以当前素材和玩法合同为准。
