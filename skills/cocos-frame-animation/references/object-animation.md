# 物件、环境与机械动画

本参考用于道具、环境装饰、场景局部、机关和其他非角色主体的帧动画。完整时间轴与播放边界遵循[完整动作与时间轴](action-timing.md)；本文件补充这类动画的选择依据、运动判断和人工验收重点。

## 适用范围与边界

主体的主要表现是物体运动、部件运转、环境变化或状态切换时，使用本分类。例如摆动的挂饰、风吹的植被、水面或火焰循环、门闩转动、平台升降、机关展开和道具启用。无需为了显得有动作而给它添加角色式蓄力、战斗爆发或攻击阶段。

若重点是有意表达的能量、粒子、烟雾、冲击或光效，按[特效帧动画](effect-animation.md)判断；若运动来自身体动作、支撑和重心变化，按[角色帧动画](character-animation.md)判断；真正需要逐帧位图的按钮反馈、提示或图标按 [UI 帧动画](ui-frame-animation.md)判断。一个组合表现可以由多个独立资源承担，边界由现有资源合同决定。

用途分类不决定动画单元、视频数或运行时 key 数。循环、单次、组合播放和终态保持是独立播放设置；轻重、夸张、停顿和跟随程度按物体属性、玩法用途及项目视觉基线决定。

## 设计依据与交付内容

道具与环境动画设计师负责非角色主体的运动规律、材质表现和状态变化。任务分工遵循[动画导演／动作指导职责](animation-direction.md)：简单任务由该设计师兼任导演；需独立统筹的复杂表演或紧密跨类型协作由导演提出构思，单纯类型并列或合批不自动增加岗位。设计时读取任务定义的物件用途、触发事件、目标状态和播放去向，并按体验目标推导运动方向与范围；已有合同明确的运动范围则遵循。对照真实源图或视频、已批准参考、实际显示尺寸和项目美术基线，确认外形、比例、安装关系、材质与场景背景。运动依据可来自物件结构与材质（如刚性转轴、柔性摆动、液体或火焰流动）及已定义的外力或玩法事件；可用有依据的弹性、夸张、节奏反差或状态揭示增强趣味，不要求拘泥于物理模拟。材质表现和艺术运动空间未细化时，可根据体验目标形成设计假设；仅当既有玩法触发、机械连接或运动权限等决定性事实无法推导时才标待澄清，不自行创造新的交互状态。

交付到当前 Work Item 设计工件：

- 明确希望观众感受到的材质趣味、环境氛围或状态变化，以及最值得看的运动亮点；说明运动机制、材质反应和表演意图所依据的任务事实、真实素材或参考。
- 给出适用阶段的运动轨迹、轴心/锚点、空间变化、允许范围、加减速与启停/反向方式；按需要设计惯性、回弹、摆荡、展开、解体或局部变化等手段，并把关键状态和变化时机对应到已定义的事件或阶段。
- 说明循环接缝或单次终态、与相邻状态的交接，以及目标显示尺寸下保留的材质细节和运动层次；时长、幅度、帧数等参数从任务推导，资源形式和播放设置沿用现有合同。

## 制作与优化判断

- **让材质运动本身有趣。** 先判断物件结构和材质如何运动，再寻找有吸引力的轨迹、节奏和形态变化。刚性、柔性、液体或火焰可以分别体现不同运动气质；在不损害主体识别的前提下，允许夸张惯性、弹性回弹、反向、变形或局部解构。无需将严格物理模拟当作默认风格。
- **保持关系可读，允许设计性变化。** 固定座、轴心、接触面或悬挂点按设计关系保持连续；若表演需要脱离、展开、漂浮、移动、旋转或改变构图，应明确路径与范围，使变化有因果且观众能读懂。不能把为表现变化而设计的位移误判为主体漂移，也不能因逐帧裁切让本应静止的背景关系无意抖动。
- **让状态变化可辨。** 对开合、启用、损坏或切换状态，检查变化前后轮廓、部件位置或材质反馈是否足以区分。关键状态应在计划的玩法或环境事件附近清楚呈现；避免被快速掠过、遮挡或过度闪烁淹没。若状态还需要常驻图标或玩法数据表达，帧动画只负责合同分配给它的视觉部分。
- **按用途选循环或终态。** 环境闲置通常需要跨周期稳定；机关启动、物件破坏或一次性变化通常需要明确的到达状态。动画是否循环不能由主体类别推断，也不能在单次动画尾部自动补等待。循环应保留自然的速度与方向衔接，避免端点重复造成顿挫。
- **按目标显示尺寸删繁就简。** 缩小检查后若细小部件、细线或高频闪动无法稳定辨认，应合并细节、降低无效摆动或简化局部变化；不能靠移动锚点或压缩运动范围掩盖布局问题。应保留能传达材质、方向、状态和运行规律的细节。
- **把优化依据记在当前设计工件中。** 记录采用的运动规律、关键状态、锚点和简化理由；不为此新增报告或 accepted 字段。

## 人工验收重点

1. **先完整观看体验：** 连续播放整段动画，判断材质特征是否鲜明、运动是否有趣、状态变化是否吸引注意、节奏是否符合用途；先确认预期的位移、形态变化、弹性或环境氛围是否成立，再逐帧找实际缺陷。
2. **运动关系与材质身份：** 安装点、轴心、地面接触和前后层次按设计保持可读；外形、比例与材质变化符合该段表演意图。允许有因果的形变、伸缩、漂浮、偏移和构图变化；把无因跳位、身份变化或未设计的静止背景抖动作为问题。
3. **运动与启停是否连贯：** 摆动方向、旋转中心、滑动路径、启动、停止、反向及惯性相互衔接；同一部件在启停或反向时没有无法解释的瞬移、冻结或多余回弹。对环境循环，观察多个周期，确认变化接缝符合设计且没有无意复位闪跳。
4. **状态是否能被读出：** 动作前后和中间关键状态在实际显示尺寸下可辨；检查重点信息是否按设计突出，关键状态没有被意外遮挡或裁切，速度变化服务于观看体验与状态识别。
5. **播放边界是否符合用途：** 循环检查接缝和周期内运动；单次播放检查终态、保持或隐藏；若紧接另一个状态，检查交接动作和锚点是否符合已有合同。

## 不在本分类内决定的事项

本参考不规定固定时长、阶段比例、循环周期、视频批次大小或输出尺寸。角色发力与玩法事件、特效透明边缘和 UI 程序动效分别按各自分类及现有合同处理；未给出的状态规则或运动权限应记录为待澄清，不由动画自行创设。
