# 物件、环境与机械动画

本参考用于道具、环境装饰、场景局部、机关和其他非角色主体的帧动画。完整时间轴与播放边界遵循[完整动作与时间轴](action-timing.md)；本文件补充这类动画的选择依据、运动判断和人工验收重点。

## 适用范围与边界

主体的主要表现是物体运动、部件运转、环境变化或状态切换时，使用本分类。例如摆动的挂饰、风吹的植被、水面或火焰循环、门闩转动、平台升降、机关展开和道具启用。无需为了显得有动作而给它添加角色式蓄力、战斗爆发或攻击阶段。

若重点是有意表达的能量、粒子、烟雾、冲击或光效，按[特效帧动画](effect-animation.md)判断；若运动来自身体动作、支撑和重心变化，按[角色帧动画](character-animation.md)判断；真正需要逐帧位图的按钮反馈、提示或图标按 [UI 帧动画](ui-frame-animation.md)判断。一个组合表现可以由多个独立资源承担，边界由现有资源合同决定。

用途分类不决定动画单元、视频数或运行时 key 数。循环、单次、组合播放和终态保持是独立播放设置；轻重、夸张、停顿和跟随程度按物体属性、玩法用途及项目视觉基线决定。

## 制作与优化判断

- **先确定物理或设计规律。** 判断物体是刚性旋转、滑动、摆动、弹性形变还是环境流动，再选择轨迹与速度变化。摆件通常围绕悬挂点转动；推拉机关应沿安装方向移动；水、火等环境变化可有局部不规则性，但整体范围和节奏仍要稳定。没有物理依据的漂移、尺寸忽大忽小或无故变向会削弱主体可信度。
- **保持安装关系与语义锚点。** 固定座、轴心、接触面或悬挂点应在各帧保持一致。需要移动的部分应能看出是沿设计路径运动，不能因逐帧裁切或构图变化让静止主体抖动。若整个物件有意移动，明确起止位置和运动范围，并确认它仍满足场景布局。
- **让状态变化可辨。** 对开合、启用、损坏或切换状态，检查变化前后轮廓、部件位置或材质反馈是否足以区分。关键状态应在计划的玩法或环境事件附近清楚呈现；避免被快速掠过、遮挡或过度闪烁淹没。若状态还需要常驻图标或玩法数据表达，帧动画只负责合同分配给它的视觉部分。
- **按用途选循环或终态。** 环境闲置通常需要跨周期稳定；机关启动、物件破坏或一次性变化通常需要明确的到达状态。动画是否循环不能由主体类别推断，也不能在单次动画尾部自动补等待。循环应保留自然的速度与方向衔接，避免端点重复造成顿挫。
- **按目标显示尺寸删繁就简。** 缩小检查后若细小部件、细线或高频闪动无法稳定辨认，应合并细节、降低无效摆动或简化局部变化；不能靠移动锚点或压缩运动范围掩盖布局问题。应保留能传达材质、方向、状态和运行规律的细节。
- **把优化依据记在当前设计工件中。** 记录采用的运动规律、关键状态、锚点和简化理由；不为此新增报告或 accepted 字段。

## 人工验收重点

1. **静止关系是否稳定：** 安装点、轴心、地面接触和前后层次没有无意漂移；物件不会无故伸缩、跳位或越出允许的运动范围。
2. **运动是否符合其规律：** 摆动方向、旋转中心、滑动路径、启停速度和惯性相互一致；同一部件在反向或停止时没有不合理瞬移。对环境循环，观察连续多个周期，确认纹理或火焰变化没有明显复位闪跳。
3. **状态是否能被读出：** 动作前后和中间关键状态在实际显示尺寸下可区分，关键信息没有被自遮挡或边界裁切；速度不会快到看不清状态，也不会慢到像意外停滞。
4. **播放边界是否符合用途：** 循环检查接缝和周期内运动；单次播放检查终态、保持或隐藏；若紧接另一个状态，检查交接姿态和锚点是否匹配已有合同。

## 不在本分类内决定的事项

本参考不规定固定时长、阶段比例、循环周期、视频批次大小或输出尺寸。角色发力与玩法事件、特效透明边缘和 UI 程序动效分别按各自分类及现有合同处理；未给出的状态规则或运动权限应记录为待澄清，不由动画自行创设。
