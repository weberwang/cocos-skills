# 特效帧动画

本参考用于冲击、爆闪、粒子、能量、烟雾、光环、火焰或其他以视觉效果变化为主体的帧动画。完整时间轴与播放边界遵循[完整动作与时间轴](action-timing.md)；特效可以单独制作，也可由现有合同规定与宿主资源组合。

## 适用范围与边界

当主要信息来自效果本身的出现、扩散、峰值、衰减或消散时，按特效处理。普通主体/机关的机械运动归入[物件、环境与机械动画](object-animation.md)；身体发力、受力和位移归入[角色帧动画](character-animation.md)。特效出现的画面位置或颜色不自行规定它代表伤害、命中次数或状态权限。

特效是否烘入角色、武器、场景或 UI 帧，依现有素材合同决定。没有合同依据时不默认要求合并，也不默认要求角色素材包含光效、声音或镜头反馈。视觉特效单元可独立制作，玩法事件仍由已有系统定义。

用途不决定行为单元、视频批次、动画 key、尺寸或循环方式；单次播放、循环、组合与终态保持分别按效果生命周期和资源合同确定。效果强度、扩散幅度、停留和跟随关系按具体效果及项目视觉基线决定。

美术强度遵循[游戏美术体验与质量契约](../../cocos-game-asset-integration/references/art-quality-contract.md)：结合常态、操作反馈与关键事件峰值的语义，以及目标观看体验决定表现，不预设统一强度或克制风格。单次效果的亮度、面积和时长按任务推导，并结合实际触发频率、并发数量和混合方式评估连续游玩中的观看效果，不能仅凭独立预览选方案。

## 设计依据与交付内容

游戏特效设计师负责把已有玩法事件转化为有感染力、可在实际场景中读出的视觉反馈。任务分工遵循[动画导演／动作指导职责](animation-direction.md)：简单任务由该设计师兼任导演；需独立统筹的复杂表演或紧密跨类型协作由导演提出构思，单纯类型并列或合批不自动增加岗位。设计依据包括事件的既有语义与时点、宿主状态及生命周期、效果发生位置和现有触发频率；同时读取真实宿主素材、目标背景/显示尺寸、透明与混合合同及项目美术体验基线。形状、扩散、粒子/烟雾/能量的运动和衰减按具体效果机制与表演目标推导；没有玩法依据时，不把视觉效果解释为伤害、命中次数或新状态。

交付到当前 Work Item 设计工件：

- 明确希望观众感受到的能量、冲击、神秘感或其他效果体验，以及视觉亮点；说明形状从出现、发展、峰值到衰减/消散的演变、层级、节奏和视觉焦点，并将峰值或接触表现对应到既有触发事件。
- 标明宿主事件、锚点、扩散/跟随/遮挡轨迹、形态层次、颜色与透明/混合处理，并说明效果何时结束或保持；相关强度、范围、节奏和时长按任务推导，不要求每个效果套用同一种阶段或强弱模式。
- 结合实际触发频率、并发和宿主已有光效，说明重复触发、叠加和性能取舍；视觉单元与宿主的资源分工沿用现有合同。

## 制作与优化判断

- **按观看体验塑造形状与能量节奏。** 依据效果用途设计扩散、旋转、卷曲、聚合、爆发、拖尾、残留或消散等形态变化；选择能让观众感受到效果特性的节奏、层次和强弱。阶段、强度及停顿按任务推导，不套用统一模板，也不强制克制或强烈的单一风格。
- **与宿主事件对齐。** 记录特效由哪个现有事件触发、何时出现以及何时结束，并核对游戏时间轴。击中闪光应对应已定义的命中时刻；持续光环应对应宿主状态生命周期。若时间、重复触发或宿主行为未定义，记录待澄清，不通过多画一次特效代替玩法决定。
- **控制重复与累积。** 高频效果按项目预算规定合并、去重、冷却或并发上限；已有素材烘焙光效与运行叠加光效共同计入预算，避免加法混合连续变亮。峰值后及时衰减并回到常态，不能用延长高亮保持代替明确反馈。
- **明确表演路径与空间关系。** 选择语义根点，例如冲击中心、施法点、武器接触点或宿主附着点；根据表演需要设计扩张、偏移、旋转、跟随、穿行或沿路径移动。逐帧检查根点和运动轨迹是否连贯，保护玩法相关接触信息，并遵循素材边界与宿主遮挡合同。
- **根据效果与背景选择透明表达。** 按实际效果和消费方式决定真实 Alpha、颜色、混合方式和背景策略。半透明烟雾、柔边辉光、粒子尾迹不能作为纯色硬边去背处理；不能把它们标成硬边或用伪造的边界颜色掩盖透明度。若素材合同需要真实透明边缘，使用真实 Alpha、遮罩或逐帧修复，并检查边缘颜色污染。
- **在目标像素尺寸下优化。** 光晕、细粒子和低对比渐变缩小后可能消失或闪烁。检查峰值是否可读、衰减是否平顺、细节密度是否适合目标尺寸与帧率；必要时简化粒子层级、拉开明暗层次或减少高频变化。不能为了突出效果遮盖宿主关键轮廓或玩法反馈。
- **保留合法空帧和完整消散。** 效果已经结束后的透明帧可按时间计划保留；判断其播放边界是否真的需要空白，不擅自延长或删除计划中的消散。若是独立效果动画，按自身合同处理结束状态，不自动循环。

颜色、透明边缘、混合方式、锚点与允许位移的选择依据记在当前 Work Item 设计工件中，不新增报告或 accepted 字段。

## 人工验收重点

1. **先完整观看效果：** 在目标场景中连续观看，判断效果是否有吸引力、视觉亮点是否突出、形状变化与能量节奏是否传达任务体验；确认强弱、层次和收尾是否成立，再逐帧检查实际瑕疵。
2. **全过程、峰值与触发同步：** 查看设计的形态变化是否顺畅、关键视觉阶段是否清楚；峰值/接触表现与既有宿主事件的时点和位置对应，持续效果符合宿主生命周期，没有提前出现、重复触发或无计划残留。
3. **锚点和范围：** 冲击/附着位置与预定路径保持连贯，扩散、偏移或跟随符合设计和合同；效果主体按设计入镜，边缘没有意外越区或裁切，也不遮挡必须辨认的角色姿势。
4. **透明质量：** 在实际背景以及明暗背景上检查半透明边、光晕、烟雾和粒子，确认没有色边、方形底、黑边或错误去背；所用混合方式在实际消费上下文中表达正确。
5. **目标尺寸可读性：** 按游戏内显示尺寸播放，确认重要形态、峰值、方向、层次和衰减可辨；检查小粒子是否退化成无意噪点、柔光是否变成硬块，快速变化是否符合任务意图且没有意外频闪。
6. **播放边界与重复观看：** 单次特效检查收尾和空帧处理；循环效果跨周期检查亮度、形态和运动接缝。在实际宿主、目标尺寸与既有触发频率下检查重复触发及叠加，确认强度变化符合设计、常态与峰值各自表达清楚且收尾无意残留。由用户人工检查显示效果；只有独立单次预览时，本项保持未验证。复验长度沿用项目观看情境，不新增通用时长或独立确认门。

## 分类边界

独立特效可以独立成动画单元。是否与角色或道具共用制作批次由公共批次规划决定，不改变其事件、透明和播放合同。特效本身不授予攻击、伤害、自动连击或输入权限；这些语义沿用已有玩法定义。
