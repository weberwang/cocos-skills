# 特效帧动画

本参考用于冲击、爆闪、粒子、能量、烟雾、光环、火焰或其他以视觉效果变化为主体的帧动画。完整时间轴与播放边界遵循[完整动作与时间轴](action-timing.md)；特效可以单独制作，也可由现有合同规定与宿主资源组合。

## 适用范围与边界

当主要信息来自效果本身的出现、扩散、峰值、衰减或消散时，按特效处理。普通主体/机关的机械运动归入[物件、环境与机械动画](object-animation.md)；身体发力、受力和位移归入[角色帧动画](character-animation.md)。特效出现的画面位置或颜色不自行规定它代表伤害、命中次数或状态权限。

特效是否烘入角色、武器、场景或 UI 帧，依现有素材合同决定。没有合同依据时不默认要求合并，也不默认要求角色素材包含光效、声音或镜头反馈。视觉特效单元可独立制作，玩法事件仍由已有系统定义。

用途不决定行为单元、视频批次、动画 key、尺寸或循环方式；单次播放、循环、组合与终态保持分别按效果生命周期和资源合同确定。效果强度、扩散幅度、停留和跟随关系按具体效果及项目视觉基线决定。

美术强度遵循[游戏美术体验与质量契约](../../cocos-game-asset-integration/references/art-quality-contract.md)：区分常态、操作反馈与关键事件峰值，按玩法重要性和目标玩家体验决定表现。单次效果的亮度、面积和时长必须与实际触发频率、并发数量和混合方式一起评估，不能仅凭独立预览的冲击力选方案。

## 制作与优化判断

- **按效果的因果过程设计。** 依据真实用途判断是否需要出现、发展、峰值和消散阶段，以及各阶段如何衔接；某些效果可省去不必要阶段。不要套用统一阶段比例，也不要为了“有冲击力”一律加蓄势、停顿或爆炸峰值。
- **与宿主事件对齐。** 记录特效由哪个现有事件触发、何时出现以及何时结束，并核对游戏时间轴。击中闪光应对应已定义的命中时刻；持续光环应对应宿主状态生命周期。若时间、重复触发或宿主行为未定义，记录待澄清，不通过多画一次特效代替玩法决定。
- **控制重复与累积。** 高频效果按项目预算规定合并、去重、冷却或并发上限；已有素材烘焙光效与运行叠加光效共同计入预算，避免加法混合连续变亮。峰值后及时衰减并回到常态，不能用延长高亮保持代替明确反馈。
- **明确锚点和位移权限。** 选择语义根点，例如冲击中心、施法点、武器接触点或宿主附着点。逐帧检查根点稳定；若特效需要扩张、偏移、跟随或沿路径移动，明确允许方向与范围。不要因特效外缘变化而让接触位置无意漂移，也不能越出区域或侵入不允许的邻区。
- **根据效果与背景选择透明表达。** 按实际效果和消费方式决定真实 Alpha、颜色、混合方式和背景策略。半透明烟雾、柔边辉光、粒子尾迹不能作为纯色硬边去背处理；不能把它们标成硬边或用伪造的边界颜色掩盖透明度。若素材合同需要真实透明边缘，使用真实 Alpha、遮罩或逐帧修复，并检查边缘颜色污染。
- **在目标像素尺寸下优化。** 光晕、细粒子和低对比渐变缩小后可能消失或闪烁。检查峰值是否可读、衰减是否平顺、细节密度是否适合目标尺寸与帧率；必要时简化粒子层级、拉开明暗层次或减少高频变化。不能为了突出效果遮盖宿主关键轮廓或玩法反馈。
- **保留合法空帧和完整消散。** 效果已经结束后的透明帧可按时间计划保留；判断其播放边界是否真的需要空白，不擅自延长或删除计划中的消散。若是独立效果动画，按自身合同处理结束状态，不自动循环。

颜色、透明边缘、混合方式、锚点与允许位移的选择依据记在当前 Work Item 设计工件中，不新增报告或 accepted 字段。

## 人工验收重点

1. **全过程与触发：** 查看出现、发展、峰值、消散各段是否完整且顺序清楚；与宿主事件时刻、位置和生命周期相符，没有提前出现、重复触发或无计划残留。
2. **锚点和范围：** 冲击/附着位置稳定，允许的扩散、偏移或跟随符合合同；效果主体完整入镜，边缘没有越区、误裁或遮挡关键角色姿势。
3. **透明质量：** 在实际背景以及明暗背景上检查半透明边、光晕、烟雾和粒子，确认没有色边、方形底、黑边或错误去背；所用混合方式在实际消费上下文中表达正确。
4. **目标尺寸可读性：** 按游戏内显示尺寸播放，确认关键峰值、方向、层次和衰减可辨；小粒子不闪成噪点，柔光不变成硬块，快速变化不造成无意频闪。
5. **播放边界：** 单次特效检查峰值后的结束和空帧处理；循环效果跨周期检查亮度、形态和运动接缝。播放方式按合同判断，不由特效类别自动推断。
6. **连续游玩：** 在实际宿主、目标尺寸与正常触发频率下查看重复操作及叠加片段，确认常态不抢焦点、峰值不遮挡必要信息、收尾不残留，连续观看结果符合项目体验目标。由用户人工检查显示效果；只有独立单次预览时，本项保持未验证。复验长度沿用项目观看情境，不新增通用时长或独立确认门。

## 分类边界

独立特效可以独立成动画单元。是否与角色或道具共用制作批次由公共批次规划决定，不改变其事件、透明和播放合同。特效本身不授予攻击、伤害、自动连击或输入权限；这些语义沿用已有玩法定义。
